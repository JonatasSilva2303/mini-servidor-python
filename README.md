# Mini Servidor de Arquivos Python

Servidor HTTP desenvolvido em Python para compartilhar e baixar arquivos por meio de uma interface web, com acesso pela rede local.

## Funcionalidades

- Interface web personalizada.
- Listagem e pesquisa de arquivos.
- Exibição do tamanho dos arquivos.
- Download pelo navegador.
- Acesso por dispositivos na mesma rede local.

## Tecnologias

- Python 3
- HTML
- CSS
- JavaScript
- Linux Mint
- HTTP e redes de computadores

## Como executar

1. Instale o Python 3.
2. Entre na pasta do projeto.
3. Execute:

```bash
python3 servidor.py
```

4. Abra `http://127.0.0.1:8000` no navegador, conforme a configuração do servidor.

## Objetivo

Projeto educacional para praticar Python, desenvolvimento web e conceitos de redes de computadores.

## Segurança

Utilize apenas arquivos de teste e uma rede confiável. Não exponha diretamente à internet uma versão sem autenticação e HTTPS.
